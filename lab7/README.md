# Лабораторна робота №7: Computer Vision та багатопотоковість у C++

## Опис завдання
Розширення програми обробки відео з використанням OpenCV DNN (нейромережа ResNet-10 SSD) для детекції облич у режимі реального часу. Для уникнення блокування основного потоку (UI) важкий інференс нейромережі винесено в окремий потік.

## Вимоги до системи
- **ОС:** Kali Linux / Ubuntu / Debian
- **Компілятор:** GCC з підтримкою C++17 (`build-essential`)
- **Бібліотеки:** OpenCV (з модулем `dnn`), POSIX Threads (`pthread`), `wget`
- **Білд-система:** CMake 3.10+, Make

## Архітектура проєкту
- **`CameraProvider`** — відповідає за захоплення кадрів з вебкамери (`cv::VideoCapture`) або відеофайлу.
- **`KeyProcessor`** — обробляє натискання клавіш (`cv::waitKey`) та зберігає поточний режим роботи (`enum class ProcessMode`).
- **`FaceDetector`** — завантажує Caffe-модель (`ResNet-10`) та виконує детекцію облич в окремому фоновому потоці (`std::thread`) із синхронізацією через `std::mutex` і `std::condition_variable`, не блокуючи рендеринг відео.
- **`FrameProcessor`** — застосовує вибрані фільтри до кадру та відмальовує рамки й рівень впевненості (`confidence > 50%`) навколо знайдених облич.
- **`Display`** — виводить оброблений кадр у вікно (`cv::imshow`).

## Збірка та запуск
1. Завантажити залежності та файли нейромережі (`deploy.prototxt`, `.caffemodel`):
   ```bash
   ./preinstall.sh
   ```
2. Зібрати проєкт:
   ```bash
   ./build.sh
   ```
3. Запустити програму:
   ```bash
   ./run.sh
   ```
